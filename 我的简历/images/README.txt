# 项目图表文件夹

把你的项目产出图表（截图/导出图）放到这里，命名对应 `index.html` 里的引用：

| 文件名 | 对应项目 | 建议内容 |
|---|---|---|
| `jd618-chart.png` | 京东618用户行为分析 | 用户-品类-地域交叉热力图 / 帕累托图 |
| `bankloan-chart.png` | 银行贷款信用风控 | ROC 曲线 / 特征重要性条形图 |

## 使用方法

1. 把你的图表导出为 PNG（建议宽 480px 以上，白底）；
2. 保存到本文件夹，文件名对上表；
3. 刷新页面即可显示（图表位会自动从占位符切换为图片）。

> 想换其他图片？直接改 `index.html` 里 `<figure class="project-figure" data-img="...">` 的文件名即可。
> 图片只在屏幕版显示，打印版会自动隐藏，保证 A4 两页版式不变。
